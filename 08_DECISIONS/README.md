# Decisions

Esta área contiene **Architecture Decision Records (ADR)**: decisiones técnicas documentadas para responder:

> ¿Por qué elegimos esta solución y no otra?

No crear ADRs todavía. Solo deben registrarse decisiones reales, con contexto, alternativas, trade-offs y consecuencias.

Estados futuros posibles:

- `PROPOSED`
- `ACCEPTED`
- `SUPERSEDED`
- `REJECTED`
