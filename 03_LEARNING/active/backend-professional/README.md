# Backend Professional — Aprendizaje activo

Aquí se estudia el roadmap de 15 sesiones. Cada módulo contiene notas provisionales, ejercicios, preguntas de recuperación, registro de errores y un checkpoint. Los resultados de laboratorio viven en `04_LABS/backend`; la evolución del sistema vive en `05_PROJECTS/portfolio/production-api-lab`.

No es una colección de artículos terminados: escribe hipótesis, prueba, rompe, diagnostica y documenta. Promueve contenido a `02_KNOWLEDGE` solo después de comprenderlo y refinarlo.
