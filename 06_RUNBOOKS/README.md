# Runbooks

Un **runbook** es un procedimiento operativo o de recuperación reproducible.

`KNOWLEDGE` explica cómo funciona algo; un runbook indica qué hacer ante una tarea operativa o una recuperación.

Actualmente no existen runbooks reales en esta área. Se crearán cuando exista experiencia operativa verificable. No se deben escribir ejemplos como si fueran procedimientos probados.
