# Backend Professional

## Propósito

Roadmap intensivo de 15 sesiones (30 horas) para construir un modelo mental profesional de backend orientado a producción, partiendo de experiencia previa en desarrollo de software y APIs.

## Perfil y prerrequisitos

Está dirigido a una persona que ya programa y construye APIs. Se asume familiaridad práctica con Java, HTTP, Git, Linux y SQL; el tiempo se dedica a semántica, trade-offs, concurrencia, seguridad, fiabilidad, pruebas, despliegue y diagnóstico.

## Cómo navegar

- [`roadmap.md`](roadmap.md) es el mapa de sesiones, dependencias y entregables.
- [`progress.md`](progress.md) registra únicamente avance real.
- [`checklist.md`](checklist.md) convierte la competencia en criterios observables.
- [`03_LEARNING/active/backend-professional/`](../../../03_LEARNING/active/backend-professional/README.md) contiene las sesiones.
- [`04_LABS/backend/LAB_INDEX.md`](../../../04_LABS/backend/LAB_INDEX.md) planifica prácticas sin inventar resultados.
- [`05_PROJECTS/portfolio/production-api-lab/`](../../../05_PROJECTS/portfolio/production-api-lab/README.md) es el proyecto transversal.

## Método

Cada sesión dura exactamente 120 minutos: 10 de recuperación activa, 35 de teoría, 50 de laboratorio/implementación, 10 de explicación sin apuntes y 15 de revisión. El aprendizaje sigue `ENTENDER → IMPLEMENTAR → ROMPER → DIAGNOSTICAR → EXPLICAR → DOCUMENTAR`.

## Stack de referencia

Java 21+, Spring Boot, Spring Security, PostgreSQL, Flyway, Redis, JUnit, Testcontainers, Docker/Compose, OpenAPI, Actuator, Micrometer, OpenTelemetry, Git y Linux.

## 80/20 y finalización

La prioridad es comprender problemas y trade-offs antes de memorizar anotaciones. El roadmap se considera terminado cuando las 15 sesiones tienen laboratorio y checkpoint completados, el proyecto transversal tiene evidencia verificable y cada módulo alcanza promedio de autoevaluación `>= 4/5`. Completar un documento no equivale a completar una competencia.
