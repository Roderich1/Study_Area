# Sistema de aprendizaje

1. Elegir el siguiente tema en un roadmap.
2. Trabajarlo en `03_LEARNING` mediante recuperación activa, teoría y práctica.
3. Registrar el experimento reproducible en `04_LABS` y la evolución del proyecto en `05_PROJECTS`.
4. Consolidar solamente lo comprendido en `02_KNOWLEDGE`.
5. Crear runbooks, incidentes o ADRs únicamente cuando exista experiencia real.
6. Seleccionar evidencia verificable para `13_PORTFOLIO`.

Para Backend Professional, cada sesión dura 120 minutos y sigue: `ENTENDER → IMPLEMENTAR → ROMPER → DIAGNOSTICAR → EXPLICAR → DOCUMENTAR`.
