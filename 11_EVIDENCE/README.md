# Evidence

Aquí vivirán evidencias pequeñas y verificables, enlazadas desde el laboratorio o proyecto correspondiente:

- screenshots;
- logs relevantes;
- salidas de terminal;
- diagramas;
- reportes;
- traces;
- pequeños artefactos de laboratorio.

No subir ISOs, backups, imágenes de máquinas virtuales, datasets grandes, dumps grandes ni secretos.
