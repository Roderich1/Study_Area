# Seguridad

Estado: `PLANNED`.

El proyecto practicará autenticación, autorización por objeto/propiedad, hashing de contraseñas, validación, SQL injection, SSRF, CORS/CSRF, rate limiting, headers, secrets y least privilege.

No guardar credenciales reales. Usar `CHANGE_ME`, `example` o `localhost` en documentación. Los ataques serán controlados, sobre datos propios y con resultado documentado únicamente después de ejecutarlos.
