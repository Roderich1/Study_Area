# Despliegue

Estado: `PLANNED`.

La topología de práctica podrá incluir API, PostgreSQL, Redis y reverse proxy mediante Docker Compose. Se estudiarán multi-stage builds, configuración, healthchecks, readiness/liveness, TLS, secretos y rollback.

Los valores de entorno serán de ejemplo (`CHANGE_ME`, `localhost`); nunca se guardarán secretos reales. Un despliegue será `VERIFIED` solo con una ejecución reproducible y validada.
