# production-api-lab

Proyecto transversal incremental del roadmap Backend Professional. Es un sistema controlado para practicar API design, PostgreSQL, constraints, migraciones, transacciones, concurrencia, autenticación, autorización, seguridad, idempotencia, caché, testing, eventos, containers y observabilidad.

## Estado

- **PLANNED:** alcance y documentación inicial definidos.
- **IMPLEMENTED:** todavía no declarado; se marcará por componente cuando exista código.
- **VERIFIED:** todavía no declarado; requiere pruebas y evidencia reproducible.

No es un producto comercial ni un proyecto terminado. Crece sesión por sesión y no se deben inventar arquitectura implementada, decisiones aceptadas o resultados.

## Dominio de práctica

`users`, `products`, `inventory`, `orders`, `order_items` y `payments`.
