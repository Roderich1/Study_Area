# Incidents

Un **incidente** es un fallo que ocurrió realmente y que debe poder reconstruirse con evidencia. Un `LAB` es un experimento controlado; no se deben confundir.

**No registrar incidentes ficticios.**

Un incidente real podrá contener:

- resumen;
- impacto;
- timeline;
- causa raíz;
- factores contribuyentes;
- solución;
- acciones correctivas;
- acciones preventivas;
- validación.
